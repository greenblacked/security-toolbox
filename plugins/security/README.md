# Security plugin

Skills adapted from [greenblacked/AI](https://github.com/greenblacked/AI) `plugins/security` for platform, cloud and infrastructure security work.

Currently included (summaries; full originals live in the AI repo):

- `iac-review` — Terraform/OpenTofu plan review against plan JSON, blast radius first
- `image-hardening` — Dockerfile and container image hardening
- `secret-rotation` — planned or incident credential rotation without outage or leftover copies

More skills (access-review, host-hardening, security-review, threat-model, dependency-triage, etc.) can be added the same way.

Install as a Claude Code plugin once the marketplace entry is added, or use the SKILL.md files directly as procedures.
