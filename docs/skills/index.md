# Security skills

Defensive review procedures adapted from the Security plugin. Each page summarizes when and how to use the skill.

- [Access Review](/skills/access-review/): Review identities and grants against usage evidence; use an observation window long enough to cover periodic work.
- [Certificate Automation](/skills/certificate-automation/): Inventory certificates and automate issuance and renewal.
- [Compromise Evidence Preservation](/skills/compromise-evidence-preservation/): Preserve evidence during a suspected compromise.
- [Dependency Triage](/skills/dependency-triage/): Turn dependency alerts into risk-based decisions.
- [Detection Engineering](/skills/detection-engineering/): Build and maintain testable security detections.
- [Host Hardening](/skills/host-hardening/): Harden a Linux host against a named baseline without losing access.
- [IaC Review](/skills/iac-review/): Review a Terraform or OpenTofu change against its plan.
- [Image Hardening](/skills/image-hardening/): Review container builds and image security.
- [Secret Rotation](/skills/secret-rotation/): Rotate credentials with a planned or incident-specific procedure.
- [Security Review](/skills/security-review/): Review a change for reachable security weaknesses.
- [Threat Model](/skills/threat-model/): Model threats at the design stage.
