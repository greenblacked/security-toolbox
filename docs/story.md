# The Security Toolbox story

Security Toolbox brings platform security guidance, read-only checks, and hands-on practice into one place. It grew from a practical question: how do you turn a security recommendation into something you can verify and hand off?

## Start with evidence

Use the [security flow](/start/) to choose a control and record what you observe. The [checks](/checks/) help you inspect existing configurations, and the [policies](/policies/) help you review changes before they ship.

## Practice the handoff

Use the [labs](/labs/) to practice on fixtures, record the outcome, and compare it with the expected evidence. The [team responsibilities guide](/teams/) describes who validates controls, who investigates signals, and who carries the findings forward.

## Where to go next

Browse the [security domains](/about/) for platform-specific guidance, or start with the [threat model lab](/labs/threat-model/) if you need to turn an open question into a backlog.
